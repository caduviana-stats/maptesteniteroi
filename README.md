# maptesteniteroi

Mapa da Saúde em Niteroi

Este projeto apresenta um mapa interativo dos serviços e equipamentos da Secretaria de Saúde do município de Niterói. A aplicação reúne e consolida informações disponibilizadas pelo SIG Niterói, permitindo consultar a localização, o tipo de serviço, o endereço, o horário de funcionamento, o telefone, o público atendido, a área de abrangência, o e-mail e outras informações de cada equipamento.

O mapa também representa as cinco regiões administrativas do município — Leste, Norte, Oceânica, Pendotiba e Praias da Baía — e permite filtrar os equipamentos por região e categoria. Além disso, conta com pesquisa por nome, serviço, bairro ou endereço, contador de pontos visíveis e painel lateral com os detalhes de cada unidade.

Desenvolvida com HTML, CSS, JavaScript e Leaflet, a aplicação consulta diretamente as camadas públicas do SIG Niterói, consolida registros provenientes de diferentes bases e utiliza cruzamento espacial para identificar os bairros e as regiões administrativas correspondentes. O mapa foi estruturado para funcionar sem chave de API e pode ser publicado gratuitamente por meio do GitHub Pages.
